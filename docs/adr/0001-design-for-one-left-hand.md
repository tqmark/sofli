# Design the complete input system for one left hand

The user cannot use the right hand but can use every finger of the left. The right Sofle half is therefore physically disconnected, and every required typing, coding, navigation, recovery, Bluetooth, and flashing action must be reachable from the left half. Familiarity, low fatigue, reliable recovery, and a small memory burden take priority over filling every available position or preserving a conventional two-handed Sofle design.

## Consequences

The inactive right-half bindings remain in the ZMK matrix only because the Sofle shield requires the full matrix. The useful design surface is the left half, with layers and macOS integration supplying the missing keys. Recommendations that require a right-hand key are invalid even when they are conventional keyboard practice.
